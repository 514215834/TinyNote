# TinyNote

部署在 GitHub Pages 上的**本地优先（local-first）Markdown 笔记应用**：纯前端（Vue 3 + TypeScript）、无后端，笔记数据全部保存在你自己的浏览器中，随时可导出带走。支持 PWA 离线使用与安装到桌面。

## ✨ 功能（v1.1）

- Markdown 笔记新建 / 编辑 / 删除（软删除）
- **PWA**：离线打开（Service Worker 预缓存 + 导航回退）、安装到桌面、检测到新版本时提示「刷新更新」
- **历史版本快照**：内容变化超 20% 自动快照，支持手动快照与一键回滚（回滚前自动存档当前内容），每篇保留 20 条
- **备份提醒**：超过 7 天未导出全量备份时启动横幅提醒，一键备份
- **存储持久化**：启动申请 `navigator.storage.persist()`，数据菜单展示用量与持久化状态
- **CodeMirror 6 编辑器**：Markdown 语法高亮、可选行号（统计栏切换）、分栏下编辑/预览滚动联动
- **图片粘贴/拖拽**：图片自动存入本地附件库，正文插入内部引用，预览直接显示；不再被引用的附件自动清理
- **大纲（TOC）**：预览态展示标题大纲，点击平滑跳转
- **导出**：单篇 `.md`、全部笔记 `.md zip`；**全量备份** `tinynote-backup.zip`（含附件，可还原导）
- **备份导入**：支持 v0.3 起 zip 与 v0.1–v0.2 的 JSON 备份，版本校验 + 自动迁移，覆盖恢复前确认
- Markdown 预览支持表格、删除线、**任务列表**、**脚注**；`html: false` 安全基线
- **文件夹**（单层）：侧边栏管理、拖拽或菜单移动笔记、删除后笔记自动移回未分类
- **标签**：编辑器内打标签，侧边栏标签云点击过滤
- **置顶**：重要笔记固定在列表最前
- **回收站**：恢复 / 彻底删除 / 清空，进入超 30 天启动时自动清理
- **自动保存**：输入防抖 + 失焦即存 + 关页兜底，无需手动保存
- **搜索增强**：关键词高亮、按文件夹/标签过滤、显示结果数（标题命中优先）
- **快捷键**：`Ctrl+N` 新建 · `Ctrl+K` 搜索 · `Ctrl+E` 预览 · `Ctrl+D` 删除
- **统计信息**：字数 / 字符数、创建与更新时间
- 深浅色主题：跟随系统，可手动切换（编辑器主题同步切换）
- **外观定制与存储管理**：主题色/字体/字号/行宽、环境光晕开关；缓存与存储管理（用量/配额/持久化、离线缓存清理、清空全部数据双重确认）（v0.5）
- **全局搜索（Ctrl+K）**：命令面板搜索标题/标签/摘要/正文，键盘导航，与侧栏搜索共用状态（v0.5）
- **GitHub Gist 同步**：全量数据同步到私有 Gist，三方合并 + 冲突副本保留，可选 AES-GCM 端到端加密（v0.6）
- **命令面板与 i18n**：Ctrl+P 命令面板（插件化命令注册表）、中/英双语界面（v1.0）
- **万级笔记性能**：长列表虚拟化、大库自动切换 MiniSearch 倒排索引、启动时间预算打点（v1.0）
- **双链（Wiki Links）**：正文 `[[标题]]` / `[[标题|别名]]` 纯文本约定，预览可点击（同名多篇候选消歧、断链一键新建同名笔记）；编辑器输入 `[[` 标题补全浮层；重命名时一键「更新全部引用」（v1.1）
- **出入链接面板**：编辑器侧栏「链接」页签——反链（±40 字引用摘要）与出链（断链标记），点击行跳转（v1.1）
- **关系图谱**：`/graph` 路由，自研轻量力导向图（SVG + rAF，零图库依赖）；节点按文件夹着色、半径按链接度；点击跳转、hover 高亮邻接、滚轮缩放与平移；大库自动降级——默认仅渲染当前过滤子集（≤ 500 节点，超出按链接度截断），全库模式显式确认后渲染（v1.1）
- 数据存 IndexedDB，纯本地，不出浏览器

## 🛠 技术栈

Vue 3（`<script setup>` + TS）· Pinia · vue-router（Hash）· Dexie/IndexedDB · CodeMirror 6（vue-codemirror）· markdown-it + highlight.js + 脚注/任务列表插件 · fflate（zip 备份）· vite-plugin-pwa（Workbox）· Tailwind CSS 4 · Vite · Vitest

## 快速开始

```bash
npm install
npm run dev        # 本地开发 http://localhost:5173
npm run test:run   # 单元测试
npm run build      # 类型检查（vue-tsc）+ 构建，产物在 dist/
npm run preview    # 本地预览构建产物
```

## 部署到 GitHub Pages

push 到 `main` 分支后，[deploy.yml](./.github/workflows/deploy.yml) 会自动执行：`npm ci` → 测试门禁 → 构建（自动注入 `VITE_BASE=/<仓库名>/`）→ 发布到 GitHub Pages。只需在仓库 **Settings → Pages → Source** 中选择 **GitHub Actions**。

## 设计要点

- **纯静态可部署**：GitHub Pages 托管，Hash 路由 + `base` 子路径适配，无任何服务端依赖。
- **local-first**：核心数据存 IndexedDB（Dexie），localStorage 只存 UI 偏好；离线可用。
- **可迭代架构**：Repository 数据层抽象（存储实现可替换）+ 数据 schema 版本化迁移（只增不破）。
- **数据安全出口**：软删除 + 全量备份导出/导入 + GitHub Gist 同步（v0.6 落地），不丢数据是每个版本的发布前提。

## 迭代路线

当前进度：**v1.1 已实现**（v0.5 外观/性能/全局搜索、v0.6 Gist 同步、v1.0 i18n/命令面板/万级性能、v1.1 双链/出入链接面板/关系图谱均已上线）。后续规划：v1.2 导入互操作 → v1.3 浏览器剪藏扩展 → v1.4 排版与素材；v2.0 本地智能为草案（不承诺排期）。详见 [ROADMAP](./docs/ROADMAP.md)。

> 说明：TinyNote 保持纯 Web/PWA 形态（可安装到桌面的是浏览器 PWA 能力），不做 Electron/Tauri 桌面应用打包；**移动端体验专项为明确排除项**（2026-10-27 决策，详见 ROADMAP §10.7）。
